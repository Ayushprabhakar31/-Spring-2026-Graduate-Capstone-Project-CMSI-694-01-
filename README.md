# PulseOps

AI-native security operations suite with live telemetry, incident workflows, and presentation-ready views.

## Deploy Backend On Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Ayushprabhakar31/-Spring-2026-Graduate-Capstone-Project-CMSI-694-01-.git)

This repo includes a `render.yaml` blueprint that provisions:

- `pulseops-backend` from `backend/src`
- `pulseops-frontend` from `frontend`

If you only need the backend first, use the same repo on Render and select the `pulseops-backend` service from the blueprint.
